# Sources — bluespot

Every dataset used by the pipeline, with retrieval provenance. Per-tile
download records live in `<data_root>/dem/MANIFEST.jsonl` on Google Drive
(regenerated by `pipeline/fetch_dem.py`).

1. USGS 3DEP — 1 meter Digital Elevation Model, project
   IL_4_County_QL1_LiDAR_2016_B16 (Cook Co. QL1 lidar, published 2024-11-18).
   Citywide: 18 tiles x42–x45 / y462–y466 covering the City of Chicago
   bounding box (pilot tile USGS_1M_16_x44y465 retrieved 2026-08-17; the
   other 17 retrieved 2026-08-17). Via TNM Access API
   (https://tnmaccess.nationalmap.gov/api/v1/products). CRS: as delivered
   (UTM 16N, NAVD88). Public domain.
   Note: the TNM query also returns overlapping tiles from IL_MidNorth_D22
   (2022) and IN_Indiana_Statewide_LiDAR_2017; those are deliberately
   excluded (`fetch_dem.py <aoi> IL_4_County`) so the whole mosaic is one
   2016 acquisition with no cross-vintage seams.

2. OpenStreetMap water polygons (natural=water incl. the Lake Michigan
   multipolygon relation 1205149, waterway=riverbank) via Overpass API,
   citywide AOI + 0.02 deg. Retrieved 2026-08-17. © OpenStreetMap
   contributors, ODbL. Used as drainage outlets only, not displayed.
   Pool working names reverse-geocoded from OSM Nominatim (1 req/s, top
   pools only), retrieved 2026-08-17.

3. City of Chicago boundary — "Boundaries - City", Chicago Data Portal
   dataset qqq8-j68g (https://data.cityofchicago.org/d/qqq8-j68g), GeoJSON
   export via
   https://data.cityofchicago.org/api/geospatial/qqq8-j68g?method=export&format=GeoJSON
   Retrieved 2026-08-17. Saved as `data/aoi/chicago.geojson`. Used as the
   product mask (depth is computed with a 1 km halo beyond it, then clipped
   to it) and for the pools `edge_truncated` flag.

4. Basemap (viewer only): Esri World Topographic Map raster tiles. Display,
   not analysis.

5. ISWS design-storm depths (scenario bookmarks, pipeline/scenario.py):
   Bulletin 70 (Huff & Angel 1989), Northeast Illinois section, 100-yr 24-hr
   = 7.58 in; Bulletin 75 (Angel & Markus, "Precipitation Frequency Study
   for Illinois", ISWS, March 2020), Section 2 (Northeast, incl. Cook Co.),
   24-hr: 2-yr = 3.34 in, 100-yr = 8.57 in. Verified 2026-08-17 from the
   lead author's IAFSM presentation (Markus, "Revised Bulletin 70 / New
   Bulletin 75", Table 5.4 + 100-yr comparison maps),
   https://www.illinoisfloods.org/content/documents/3a_revised_bulletin_70.pdf,
   cross-checked against Prairie Research Institute,
   https://www.prairie.illinois.edu/news/features/hidden-dangers/ (8.57 vs
   7.58 in for the Chicago area). The 1.0 in bookmark is a reference
   nuisance rain, not a design storm.
